# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. The app allows users to search for a city and view its current weather information.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Display humidity
- 💨 Display wind speed
- ☁️ Display current weather condition
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and API integration
- **Weather API** – Fetching weather information
